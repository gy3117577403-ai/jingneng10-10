- 用户确认方案与必要配置，助手执行获准范围内的搭建、接口、测试和交付。
- 指定 Git 仓库为 `gy3117577403-ai/jingneng10-10`，分支和每次更新都需要可追溯，避免遗漏及重复工作。

## 当前实施路线

F0 已按 Frappe 独立自定义应用实施：Frappe 16.51.0、MariaDB 11.8.9、Redis 7.4.11、Docker Compose，自有源码在 `apps/jingneng`。不安装 ERPNext 业务模块，不修改 Frappe 核心源码。当前验收页使用 Frappe 原生页面机制；Vue/Frappe UI 员工工作台仍属于 F1 的界面建设。

已具备登录、只读演示角色、9 个部门、成套/钣金各一条演示记录、私有附件的框架能力和后台任务连通检查。两个演示账号共用一个演示角色，企业岗位和跨部门规则尚未落地。检查任务保存在短期缓存中，不等于正式业务任务账本。

后续建设核心业务对象、资料版本、持久任务、AI 候选与人工核对、运行记录、导出和恢复。AI 入口目前明确禁用，没有模型输出和付费调用；真实调用需要后续配置。已有框架能力不等于完整业务流程已经实现。
