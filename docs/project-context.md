# 当前方向与进度

## 已确认的方向

- 建设面向定制制造的协作软件，使 AI 能参与资料处理、协作和后续经营生产流程。
- 新系统重建；历史数据通过上传整理，不把旧系统 API 对接作为前置工作。
- 同时组织结构化记录与文件资料，并保留关联与来源。
- 先建立可以运行和验证的软件地基，再逐步补齐真实字段与业务规则。
- 第一版用成套、钣金两类演示场景同步验证售前流程；不连接正式生产。
- 用户确认方案与必要配置，助手执行获准范围内的搭建、接口、测试和交付。
- 指定 Git 仓库为 `gy3117577403-ai/jingneng10-10`，分支和每次更新都需要可追溯，避免遗漏及重复工作。
