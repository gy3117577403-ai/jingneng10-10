## 当前实现路线

采用 Frappe 16.51.0 独立自定义应用，MariaDB 11.8.9、Redis 7.4.11、Docker Compose。源码在 `apps/jingneng`，不安装 ERPNext 模块，不修改 Frappe 核心。F1 前端使用 Vue 3.5.43 / Frappe UI 1.0.0，依赖锁文件随源码提交。

F0 已有登录、9 个部门、两类演示种子、服务与后台队列检查及配套备份。F1 增加工作台、询价/产品行、私有原件的不可覆盖版本、持久协作任务、活动记录与快照 ZIP。任务由人工分派、回复和确认，不能把 F0 短期缓存中的环境检查当业务任务，也不能把 F1 人工协作当模型推理。

演示销售能创建本人负责的询价并分派/确认任务，技术只进入被指定的记录参与协作。部门目录不会自动授权整个部门；全企业岗位权限矩阵尚未适配。详细动作、限制和使用方法见 [工作台说明](workbench.md)。
