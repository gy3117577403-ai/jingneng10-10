# ΣEM 工作区界面与交互（接续至 JN-0016）

JN-0009 在 JN-0008 完成后开始，JN-0010 继续整理导航、工作收件箱与专注核对。沿用 [JN-0005 设计约定](ui-workspace.md)。它修改实际运行的 ΣEM 应用，覆盖公共布局和组件，并重做首页与关键业务交互。入口仍是 `http://127.0.0.1:8090`，配置、账号、数据库和附件继续使用原来的本机环境。

## 使用方式

- 首页默认“待我处理”（保留旧浏览器已选视图）；“工作概览”和“分析看板”仍可切换。收件箱直接汇总售前未结束处理、待处理/临期报价、待执行订单、逾期发票和待跟进线索；负责人范围、可见事项、本人发起的售前处理分别筛选。数字来自原记录，查询失败和暂无事项分别显示。
- 左侧上部切换七个工作领域，中部平铺模块；同一模块的列表、明细、日历等移到正文顶部。底部可收起为图标栏。窄屏通过顶栏菜单或查找进入全部功能。所有入口仍来自服务器过滤后的原菜单，原路由和服务器权限保留。
- `Ctrl / Command + K` 打开统一查找；支持页面名称、询价名称/编号/客户、报价和订单名称/编号、售前文件名。它不检索文件正文，也不检索全部 ERP 对象。业务结果每类最多 8 条，完整列表通过对应模块进入。↑/↓ 选择、Enter 打开、Escape 关闭；常用页面可收藏，最多 12 项，左侧展示前 5 项。
- 收件箱支持关键词、类型、关注与分页。每类先加载最多 50 项，界面明确提示真实总数及截取限制；查找先在服务器执行，再截取。单页 25 项，不把列表长度当完整库总量。
- 点开事项后右侧显示详情；售前事项有任务、资料、记录三个标签。面板可调宽、展开，关闭后回到原事项；完整核对页提供返回待办入口。关注、收藏、侧栏宽度和收件箱筛选按当前账号保存在本机，不写入业务记录，不在浏览器保存原件内容。
- 页面查找底部可切换紧凑/舒适密度；顶栏保留浅色/深色主题。旧“专业”主题映射为统一浅色界面。
- 共用业务列表默认显示列表；既有标签选择记忆仍有效。表格的“本页筛选”和“显示列”按需展开；列顺序、显隐继续使用原来的浏览器记忆。不会把本页筛选宣传为全库查询。手机宽度采用原有摘要列表和筛选入口。
- 报价、订单详情把审核与变更字段收起；已有内容或服务端校验错误时自动展开。更新按钮走原有接口，JN-0011 增加异步保存与冲突校验，失败保留输入。编辑后离开会提示；成功写入本标签页的临时草稿可在同一版本恢复。浏览器关闭、手动输入新网址等动作不经过页面内确认，草稿也不是跨电脑备份。
- 删除、锁定、转换等原来使用 `confirm()` 的操作改为应用内对话框，必须等待明确选择；取消不发起写入。重复点击不排队重放操作。没有修改服务端写入权限或业务校验。
- 售前支持收起询价列表进入专注核对，调节候选/来源双栏比例；来源保持版本、原文与行号。资料可在权限校验后的原下载接口预览 TXT/CSV、图片和 PDF；其他格式保留下载。AI 核对时保留候选、原文定位和确认操作；完成后先展示回执，候选与来源收起以备查看。真实模型尚未配置时隐藏全局聊天悬浮入口，售前的“模拟测试”仍可用。

## 设计约定

使用 220 px 导航（收起为 64 px）、56 px 顶栏、24 px 正文边距；窄屏自适应。冷白、中性灰、石墨文字、蓝色操作强调，状态仍有语义颜色。正文约 14 px，辅助约 12 px；表格和表单紧凑，但不填入虚构指标补空白。

公共样式在 `apps/sem/resources/css/workspace.css` 与 `focused-workspace.css`，页面工具在 `resources/js/workspace.js`，确认与离开提示在 `resources/js/ui/`。不加载 Nunito 远程字体；主要详情页的 jQuery 使用随软件打包的本地文件。动效保持短促，尊重系统减少动态效果设置。

## 验收范围与边界

实际执行记录见 [JN-0009](changes/JN-0009.md) 与 [JN-0010](changes/JN-0010.md)。浏览器检查使用虚构记录，包含快捷查找、密度持久化、明暗切换、表格筛选/显隐、详情保存与离开提示、模板创建/取消删除/确认删除、售前回执、手机菜单与列表；截图仅用于视觉检查。

全菜单入口检查只证明登录后能抵达对应页面；组件回归、真实 HTTP 流程及浏览器操作分别记录，不能据此宣称上游每个业务功能均已适合企业生产。真实 AI、工程有效版本、正式计价和审批规则、岗位权限矩阵和国内财税规则仍按各自后续任务推进。

## 接续与回退

JN-0009 / JN-0010 没有数据库迁移；JN-0011 有增量销售来源结构，详见对应记录。当前运行镜像为 `jingneng/sem:jn-0016`；各中间批次的增量结构见对应更新记录。用户要求暂不做换电脑迁移，旧迁移包保持原样。源码回退使用新的 revert 提交，然后按回退源码重新构建本机环境。数据库与私有文件按配套备份恢复，不把聊天或 Git 单独当作数据备份。

新组件及许可证见 [界面依赖记录](ui-dependencies.md)。Base UI 负责弹窗基础行为，Motion 用于短促切换，Lucide 用于新增 SVG 图标；没有引入另一套全局 CSS 框架。

## JN-0011 连续销售操作

客户页增加询价入口和最近可见询价；询价、报价及订单展示可回溯的来源关系。报价与订单保留三个常用页签，其余放入“更多”，页签随地址保留。明细改为统一侧栏，保留未保存关闭确认，添加第二条明细的入口始终可见。客户/报价/订单列表保留筛选、页码和位置，失败可重试。主信息表单、询价和报价确认支持有版本约束的临时草稿。具体使用、范围和限制见 [销售关联说明](sem-sales.md)，实际证据见 [JN-0011](changes/JN-0011.md)。

## JN-0016 中文文字与连续资料工作区

公司资料的日常入口调整为“资料库、资料助手、协作待办”。导入记录和有管理权限才能访问的分类与权限收进“管理”。资料库内部区分名称/编号/台账查询与正文检索，避免暗示名称搜索会自动查文件正文。目录可以搜索、展开分支或整体收起；长名称以单行省略并提供完整悬停文字。没有隐藏或重命名旧测试记录来制造界面效果。

资料详情采用正文工作区。打开文件后自动显示授权原文，旁边按需展示信息、协作、版本和权限；持续阅读不用连续打开两个弹窗。返回时恢复原分类、筛选、列表滚动和触发焦点。协作入口返回“协作待办”，资料库入口返回“资料库”。未发送评论离开或切版前使用应用内确认；取消保留输入，确认放弃后清空。编辑和正式审批仍使用有提交与关闭保护的表单。

助手与正文检索的引用在宽屏右侧打开原文，原结果继续保留；宽度不足时把原文排在结果上方，并定位到原文区域。关闭来源后仍保留问题、结果和输入。来源首次打开固定在引用的版本及位置；主动选择其他版本时重新从该版本首页/首行阅读，避免沿用另一版本的页码。历史会话默认收起，切换资料库/助手保留当前未发送问题。页面刷新不是草稿备份。

读取 Office 页、PDF 和图片时可选择适应宽度、125%、150% 或200%显示；长页在文档内部滚动。专注阅读扩大正文区域，Escape 先退出专注；再次离开仍检查草稿。原件中的字形、版式和边距由原文件决定，界面字体调整不会重排扫描件或 Office 原文。阅读、下载、编辑仍分别接受服务器授权，收起按钮不代替权限检查。

共用文字采用本机系统字体栈，Windows 中文使用微软雅黑 UI / 微软雅黑回退；没有联网字体依赖。工作列表主文字约14 px，原文摘录与可重排正文15 px，辅助文字12–13 px，页面标题22–24 px；数字使用等宽数字特性。颜色由共用变量管理，浅色为冷白与石墨文字，蓝色用于操作和选中。深色主题仍保留，不通过降低整块透明度制造层级。共用组件、收件箱、销售核对区同步采用这些规则。

本批不新增业务表、不改变权限模型、不配置模型 API。资料助手仍明确展示“原文检索”“未使用 AI”；模拟流程测试保持独立标识。本批验收范围是上述核心路径和共用组件，不代表所有上游 ERP 页面都已逐屏重新设计。实际检查、残余限制见 [JN-0016](changes/JN-0016.md)。
