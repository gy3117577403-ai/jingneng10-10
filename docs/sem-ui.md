# ΣEM 工作区界面与交互（JN-0009）

本批在 JN-0008 完成后开始，沿用 [JN-0005 设计约定](ui-workspace.md)。它修改实际运行的 ΣEM 应用，覆盖公共布局和组件，并重做首页与关键业务交互。入口仍是 `http://127.0.0.1:8090`，配置、账号、数据库和附件继续使用原来的本机环境。

## 使用方式

- 首页默认“工作概览”：最近询价、订单、报价与常用入口使用真实演示库数据；可以切换“今日事项”和“分析看板”，原来的看板调整功能仍保留。首页视图保存在当前浏览器；旧版账户中的首页视图配置不再决定这个新入口。
- 左侧分为协作与资料、销售与客户、计划与制造、采购与仓储、质量与交付、经营与管理、设置与工具。工作台和售前工作台固定在前。分组前保留原始权限条件，再交给 AdminLTE 过滤；手机菜单从同一份过滤结果生成。
- `Ctrl / Command + K` 打开页面查找，输入“报价”“库存”等名称；上下方向键选择，Enter 打开，Escape 关闭。它只检索当前账号已有的菜单入口，不检索业务记录或文件内容。业务搜索保留在顶栏。
- 页面查找窗口底部可切换紧凑/舒适密度，保存在当前浏览器。顶栏提供浅色/深色主题；旧“专业”主题在中文工作区映射为统一浅色界面。
- 共用业务列表默认显示列表；既有标签选择记忆仍有效。表格的“本页筛选”和“显示列”按需展开；列顺序、显隐继续使用原来的浏览器记忆。不会把本页筛选宣传为全库查询。手机宽度采用原有摘要列表和筛选入口。
- 报价、订单详情把审核与变更字段收起；已有内容或服务端校验错误时自动展开。更新按钮仍走原有保存接口。编辑后点击页面链接离开，会询问继续编辑或放弃；浏览器关闭、手动输入新网址等浏览器外部动作不在这个页面内确认机制的覆盖范围。
- 删除、锁定、转换等原来使用 `confirm()` 的操作改为应用内对话框，必须等待明确选择；取消不发起写入。重复点击不排队重放操作。没有修改服务端写入权限或业务校验。
- 售前 AI 核对时保留候选、原文定位和确认操作；完成后先展示回执，候选与来源收起以备查看。真实模型尚未配置时隐藏全局聊天悬浮入口，售前的“模拟测试”仍可用。

## 设计约定

使用 204 px 导航、56 px 顶栏、24 px 正文边距；窄屏自适应。冷白、中性灰、石墨文字、蓝色操作强调，状态仍有语义颜色。正文约 14 px，辅助约 12 px；表格和表单紧凑，但不填入虚构指标补空白。

公共样式在 `apps/sem/resources/css/workspace.css`，页面工具在 `resources/js/workspace.js`，确认与离开提示在 `resources/js/ui/`。不加载 Nunito 远程字体；主要详情页的 jQuery 使用随软件打包的本地文件。动效保持短促，尊重系统减少动态效果设置。

## 验收范围与边界

实际执行记录见 [JN-0009](changes/JN-0009.md)。浏览器检查使用虚构记录，包含快捷查找、密度持久化、明暗切换、表格筛选/显隐、详情保存与离开提示、模板创建/取消删除/确认删除、售前回执、手机菜单与列表；截图仅用于视觉检查。

全菜单入口检查只证明登录后能抵达对应页面；组件回归、真实 HTTP 流程及浏览器操作分别记录，不能据此宣称上游每个业务功能均已适合企业生产。真实 AI、工程有效版本、正式转报价、岗位权限矩阵和国内财税规则仍按各自后续任务推进。

## 接续与回退

本批没有数据库迁移。运行镜像更新为 `jingneng/sem:jn-0009`，备份、验收输出、迁移包沿用新编号；旧 JN-0008 包保留。源码回退使用新的 revert 提交，然后按回退源码重新构建本机环境。数据库与私有文件按配套备份恢复，不把聊天或 Git 单独当作数据备份。
