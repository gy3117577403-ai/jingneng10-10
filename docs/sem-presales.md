# ΣEM 售前工作台（JN-0008 / JN-0011）

入口：[本机售前工作台](http://127.0.0.1:8090/zh-CN/presales)。使用现有 ΣEM 账号登录，导航中点击“售前工作台”。成套、钣金同步支持；初始提供两条明确标识的虚构演示询价。

## 使用流程

1. 新建询价，填写名称和业务类型；可选关联已有客户档案。从客户详情发起时自动带入关联。客户、交期、需求可稍后填写。
2. 在“资料”上传原件。相同资料改版时用“上传新版本”；之前的文件仍可单独下载。文件大小上限 25 MB。
3. 可以下载成套或钣金试用文本，再上传并切换“AI 辅助”。勾选最多 5 份当前版本，点击“开始模拟提取”。后台处理不依赖页面一直打开。
4. 在候选下点击“查看来源”，核对原文和行号。候选不会自动修改询价。
5. 负责人或管理员勾选要采纳的字段，必要时修订，填写审核说明，点击“确认并更新”。只修改所选字段，其他内容保持原值。也可以填写原因后驳回。
6. “操作记录”保留创建、修改、上传、协作者调整、提取和审核记录；已确认结果包含确认人、时间、说明、修改前后内容。

当前模拟适配器只读取 UTF-8 TXT/CSV 的固定标签：`客户名称：`、`期望交期：`、`需求说明：`。日期采用 `年-月-日`。缺失、多值冲突和非法日期会要求核对；不会猜补。PDF、图片、Office、CAD 目前作为原件保存，不会自动识别图纸、BOM 或尺寸。没有配置真实模型，没有产生模型 API 请求。

## 访问与提交约束

- 负责人、管理员可以编辑询价、指定协作者和确认候选。协作者可查看、上传和发起提取；不能确认写入。
- 没有被指定的普通用户看不到记录、原件、来源或运行；撤销协作后立即停止访问。部门目录不会自动授予访问权。
- 编辑与上传携带记录版本；发生冲突返回提示，保留页面输入。审核前再次检查记录版本和原件摘要。
- 同一请求重试会返回同一回执；同一资料与记录版本重复提取会打开已有运行。相同来源被驳回或取消后仍保留原记录，需要更新资料或询价再重新生成。
- 新版本或询价修改会使旧候选失效，旧记录允许查看与驳回，不能覆盖当前内容。上传“最新版本”不等于工程批准版本。
- 后台队列投递中断由调度器补投；运行超过两分钟可恢复，最多尝试三次。已取消/已确认的任务不会因重复投递重新执行。

页面保留搜索、业务类型和标签地址；有未保存修改时使用软件内确认窗口。窄屏在列表和详情间切换。JN-0011 对询价新建/编辑和报价生成增加本标签页临时草稿，最多保留 24 小时；关闭标签页、跨电脑和文件内容不在恢复承诺内。

## 数据与验证

新增七张 `jn_` 售前表，原件存于私有存储 `private/presales/`，只有带访问校验的下载接口可读取。JN-0011 增加客户关联、来源快照以及人工确认后的报价草稿，继而复用原有明细转订单；没有自动计价或自动投产。操作步骤和边界见 [销售关联说明](sem-sales.md)。

```bash
python scripts/sem.py start
python scripts/sem_presales_acceptance.py
python scripts/sem.py test
python scripts/sem.py backup
python scripts/sem.py restore-check --backup <备份目录>
```

验收只使用虚构数据，报告在 `.local/acceptance/jn-0008/`，不进入公开仓库。备份包含售前数据、来源快照、审核回执和原件。代码回退不能代替配套数据库和文件恢复。

旧 Frappe 8088 仍保留，两个系统没有同步数据。JN-0009 / JN-0010 已完成公共 UI 与导航改造，JN-0011 继续改善销售连续操作，见 [界面说明](sem-ui.md)。
