# 销售报价交互方案与真实组件预览

工作编号：JN-0022。当前是独立前端交互预览，使用虚构客户、价格、文件索引和本机演示状态。未接入8090业务、实际历史报价、供应商价格、企业审核或正式输出。

## 设计目标与本轮修正

销售的主任务是找到可参考明细，理解本次差异，补齐成本依据并完成报价核对。成套包含柜体、电气元件、辅材、装配和调试；钣金包含材料、加工及表面处理。

第一轮把项目列表、当前项目概览、历史详情和成本表单同时铺开，产生重复信息；成本在中间和右侧出现两次，历史复用按钮还可能落在首屏之外。第二轮围绕这些实际问题重排信息，保留业务能力，用按需展开代替永久并列面板。

| 页面 | 默认展示 | 按需操作 |
| --- | --- | --- |
| 报价工作台 | 一份项目列表；客户、业务、版本、期望日期、金额和下一步 | 查询、业务/状态筛选；点整行直接打开报价 |
| 历史报价 | 一个搜索框与完整五列表格，日期保留完整格式 | 点产品或行打开详情抽屉；成本默认折叠；底部固定复用按钮 |
| 报价明细 | 产品规格、图号、数量、对外单价、金额、核价状态 | 添加历史明细；展开报价说明；点核价状态进入对应产品成本 |
| 成本核价 | 当前产品与历史数量、每项成本摘要 | 一次展开一项价格和来源；确认后转到下一项；来源记录按需打开 |

编辑页的“报价明细”和“成本核价”共用同一份草稿。切换页签保留当前产品和数据；临时进入历史再返回也保留工作区。复用新增明细后回到明细页，并将新增产品作为后续核价对象。合计和下一步固定在底部。

## 视觉与组件

沿用京能品牌蓝和系统无衬线字体。主标题18–22px，正文、控件和主要明细12–13px；图号、列标题等次要信息11px；规格与成本描述不再使用9–10px。通过对齐、细分隔线和稳定的白色内容表面组织信息，减少重复卡片和并列容器。

真实使用现有 shadcn/ui Base UI 的 Button、Input、Select、Checkbox、Tabs、Sheet、Dialog、Textarea 和 Table；历史排序使用 TanStack Table。Motion 用于按钮反馈、工作区短过渡和成本连续折叠，没有新增依赖。HeroUI、Ant Design、Aceternity、Magic UI未作为运行依赖混入本批界面。

按钮34px、圆角7px；内容背景以银白为主，蓝色用于主要操作、选中页签和当前展开项。支持焦点轮廓、短促按压及减少动态效果偏好。抽屉中的详情可滚动，底部操作独立固定。窄屏报价明细改为纵向排列；历史表格保留列信息，在自身容器内滚动。

以上是设计和实现说明；实际验收范围及待复测项以 `docs/changes/JN-0022.md` 为准，不将实现直接等同于已验证。

## 业务边界

历史报价不可被草稿编辑覆盖。复用时独立复制成本对象并清除确认状态；数量、单价或成本变化后需重新核对。缺失成本保留空值，不按零计价。金额以分为单位汇总。演示核对要求有明细、有效数量和价格、成本及依据已确认；已确认成本可重新进入待核对状态。

完成演示核对后版本只读；创建修订保留原记录。客户视图只展示对外明细，不展示内部成本。移除明细后保留撤销入口，只恢复被移除项，不覆盖其他修改。

历史文件只是虚构来源索引，没有伪造可下载的Excel/PDF或图纸内容。当前没有Excel导入、真实审批、发给客户、固定正式PDF、客户接受、转订单、字段权限或官方计价规则。这些需在后续接入时沿用现有业务能力并独立验证。

## 体验路径

入口：<http://127.0.0.1:5181/quotes?view=workbench>。

1. 打开“装配车间配电改造”。默认进入报价明细，查看8台柜体的数量、未税单价和金额。
2. 点“继续核价”或明细上的“待补价格”，进入成本核价。默认只展开待处理的电气元件，其余成本保留摘要。
3. 缺价时“确认此项依据”不可用；点“核对报价”会列出未齐备项目并阻止完成。
4. 填写演示价格和来源，再点“确认此项依据”。完成全部成本确认后，勾选本次数量、配置与价格，进入演示核对。
5. 需要重核已确认成本时展开该项，点“重新核对此项”；修改价格或来源也会自动取消其确认。
6. 回到报价明细，点“从历史添加”。历史页显示当前报价上下文；可直接返回，或搜索并选择产品。
7. 历史详情在抽屉内打开，成本默认收起；底部“复用这条明细”始终保留。来自同类可编辑报价时默认加入该草稿，也可以选择新建。
8. 使用“报价单预览”检查对外信息；已核对版本可以创建修订。移除明细可撤销，刷新仍保留演示数据。

Ctrl+K进入历史页并聚焦唯一搜索框。左下角重置按钮恢复初始报价演示，保留组织预览和8090数据。

专用本地存储键：`jingneng.quotation-ui-preview.v1`。关闭页面或刷新仍保留，但不是服务器保存或业务备份。浏览器存储不可写时显示失败提示。
