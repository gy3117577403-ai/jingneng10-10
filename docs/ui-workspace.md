# 工作区设计与交互约定（JN-0005）

## 第一轮：关键页面设计

确认依据：用户授权助手完成三轮，要求紧凑、去除技术噪声、完整交互、多轮实际检查。使用当前已运行的询价/任务/资料/AI 服务，不创建另一套演示应用。

- 询价列表：左侧约 204 px 导航；顶部 56 px 工具栏；正文边距 24 px；标题与操作合并一行。表格默认紧凑，筛选、排序、列显隐按需展开，窄屏改为摘要列表。
- 询价详情：固定的标题与上下文操作，正文使用需求、资料、协作、AI、历史五个标签；导出在工具菜单中，历史导出可查看。详情直接呈现关键字段和产品，不出现开发里程碑、长编号或实现说明。
- AI 核对：原文与候选各占一栏，来源定位联动；新提取与历史按需打开；底部固定审核说明与选择汇总；终态切换为结果回执。短标签明确模拟模式，不展示伪造置信度或模型费用。

## 统一组件与状态

冷白/中性灰、石墨文字、蓝色交互强调；正文 14 px、辅助 12 px，紧凑/舒适密度可切换。采用现有 Frappe UI 的 Lucide 图标资源；不加载第三方远程字体或装饰图。层次由微弱阴影和位移反馈表达，普通内容不使用透视旋转。减少动态效果设置优先。

长表单分组、日期专用控件、错误保留输入；离开未提交内容前提醒。搜索筛选和标签写入路由，列表返回恢复位置。仅显示有数据或有下一步操作的区域；空态简短，不能靠空卡片填满屏幕。

## 第二轮与第三轮边界

重做现有登录与工作台各页面；新增按访问范围过滤的待回复/待确认/AI/挂起工作收件箱，以及完整结果集的排序和责任筛选。保留正式写入的版本核对、幂等请求、原件与审核记录。

跨设备草稿、全文跨文件检索、PDF/Office/CAD 理解、真实模型和新增业务规则不伪装成已实现控件。当前资料预览保持 TXT/CSV，其他原件可真实下载。

验证覆盖构建、已有 F0/F1/F2 回归、新收件箱与排序权限、销售和技术两角色、成套和钣金、上传版本/任务/部分采纳与驳回/下载、窄屏、焦点与错误恢复。截图只是视觉证据，不替代功能验证。实际结果写入 JN-0005。
