# 组织与成员组件预览

JN-0019 于 2026-10-13 完成本机两页可操作预览。入口为 `http://127.0.0.1:5181/`，源码在 `apps/ui-preview/`。8090 仍是既有业务应用，本预览没有替换它或接入真实人员资料。

## 设计和实现

页面由一个 224px 组织侧栏、48px 标题栏、约 41px 上下文工具栏及工作区组成。桌面标题 18px，正文与主要控件 13px，表格默认行高 40px；提供标准密度切换。细边框、灰白背景和蓝色操作重点共用同一套 token。

组织图复用 React Flow，组织节点 196×72px，成员节点 196×56px。每个父组织只绘制一条竖向主干，选中路径叠加蓝色；节点点击打开详情，独立箭头展开收起，不允许拖动节点修改组织关系。画布支持拖动、缩放、定位、适应视图。显示成员时只展开当前选中组织的直属任职，展示四人并提供完整列表入口；显式切换显示成员会按新布局适应画布。打开详情保留缩放，仅在选中节点被挡住时水平调整位置。

成员页使用真实 shadcn Table 与 TanStack Table。组织范围、核对状态、账号状态、是否包含下级、关键词可以组合筛选；支持姓名排序、分页、列显隐、密度、行选择及真实 CSV 下载。复选框和行菜单不会触发行详情。详情包含资料、任职、账号三个页签；编辑校验、保存、离开前未保存提醒可操作。

桌面详情以 340px 面板展示；小于 1150px 时覆盖工作区，手机宽度侧栏改为 Sheet，表格在自身区域横向滚动。支持键盘焦点、Enter 打开成员、Ctrl/⌘ K 搜索、Esc 关闭详情，并尊重减少动态效果偏好。没有宣称完成全量无障碍认证。

2026-10-13 根据用户反馈补充动态交互：按钮按压缩至 95.5% 后回弹，悬停抬升 1px；标签页和目录的选中背景连续移动，详情面板具有进入与退出过程，筛选与排序时表格行平滑换位。控件保留 Base UI 语义、键盘和焦点行为，动画不延迟点击生效。

组织展开、收起使用同一份插值布局驱动卡片和全部连线端点，时长 360ms，反向操作从当前帧接续。新增节点超出画布时自动平滑取景；已经可见则不改变视口。定位/适应视图为 340ms、缩放为 220ms，减少动态效果模式下直接到达目标。动效只在操作时触发，没有持续漂浮或闪烁。

## 数据和状态

初始 17 个组织、28 位虚构成员，生产计划部范围去重后 22 位（含下级和跨组织任职）。组织、任职、资料核对和演示账号状态分别展示；同一个人在范围内只计一次。所有名字、编号、邮箱、岗位、日期均用于演示。

新增和编辑只保存到当前浏览器专用 localStorage；数据不会发送给业务后端，也不会创建真实账号。刷新保存，页面菜单支持重置；保存失败时保留输入并提示。演示重置可以恢复初始数据，但不会恢复用户此前自定义的演示内容。

## 实际验收

- 20 项 Vitest 测试：原有 16 项覆盖共享主干、端点、同层无重叠、展开收起、不同子节点数量、选中稳定性、当前组织成员显示、空树/循环、跨组织任职去重、组合筛选与成员校验；新增 4 项覆盖动态端点、进入与退出、精确终点及中途反向。
- 本机浏览器实操：选择节点/成员、展开收起、全局搜索定位、显示成员、缩放与定位、详情页签、组合筛选/清空/无结果、表格排序/分页/列显隐、复选框选择与 CSV 下载。
- 实操编辑空姓名触发校验；修改岗位保存后刷新仍存在；离开未保存编辑触发提示；新增组织和成员后可在对应界面查看。验收后已将虚构数据重置。
- 已检查 1440×900、1366×768、390×844：桌面紧凑排版、窄屏独立表格滚动、手机目录与详情可操作。仅这些尺寸有实际浏览器证据，不代表所有设备都验收。
- 截图和本机验收结果保存在忽略目录 `.local/acceptance/jn-0019/`；可下载的演示 CSV 已实际读取并核对一位选择成员的内容。
- 动效补充验收：实际按住按钮测得 `scale(0.955)`；修复快速点击时固定尺寸被重新测量导致的闪空后，组织展开/收起采样 18 帧，其中 13 帧仍在移动，没有隐藏节点，端点偏差小于 0.001px。核对成员筛选从 22 人到 6 人、详情进入退出、页签键盘切换和复选框独立选择，表格行高仍为 40px。减少动态效果模拟中位移被关闭、CSS 过渡缩至 0.01ms，验收后已恢复正常模式。
- 本机保存约 11 秒实际操作的连续浏览器截图及编码 GIF：`organization-motion-demo.gif`，另有 `motion-qa.json` 和两页实际截图。录制内容为真实控件操作，没有用生成图或重绘画面代替。

构建仍有单个 JS chunk 大于 500kB 的提示；本轮不把本机预览作为生产性能结论。包体拆分、超大组织数据、后端查询、权限和并发修改冲突需在正式接入时单独验证。

## 组件真实性与接入

本轮实际使用 shadcn/ui 官方 CLI 的 Base UI/Nova 组件、TanStack Table、React Flow、Motion for React、Lucide。具体来源和版本见 [README](../apps/ui-preview/README.md)。用户列出的其他组件库作为参考，没有混入多套默认主题。

后续先以本预览确认组件、排版和交互，再将同一套工作区组件接入现有组织接口、真实登录和范围授权。不得直接拿演示账号切换或 localStorage 代替真实权限系统；预览通过不代表正式业务页面已更新。
