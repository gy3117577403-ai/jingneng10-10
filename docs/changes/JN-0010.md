## 具体变化

1. 七个工作领域、平铺模块、页面内视图和可收起导航。所有入口由原服务端授权菜单生成，兼容 PHP 权限过滤后保留数字键的对象；原入口仍可从“全部功能”找到。当前模块与视图保持高亮，手机顶栏可进入完整目录。
2. 统一查找支持页面、询价名称/编号/客户、报价和订单名称/编号、售前文件名；支持键盘选择、关闭后焦点恢复和常用页面收藏。业务查询每类最多 8 条，不声称搜索全部对象或文件正文。
3. 首页默认“待我处理”，保留概览和分析看板。只读接口按原权限聚合售前未结束处理、待处理/临期报价、待执行订单、逾期发票、待跟进线索；支持负责人、可见范围、本人发起的售前处理。每类 50 项、每页 25 项，返回真实总数并提示截取限制，关键词先查询后截取。
4. 事项右侧详情保留列表上下文，支持关注、宽度调整与展开；售前提供任务、资料、记录。桌面为非模态侧栏，手机为全屏模态窗口，关闭后恢复原行焦点。正式操作仍进入对应业务页面完成，不设置脱离业务记录的“假完成”按钮。
5. 售前专注核对可收起询价列表、调整候选/来源比例，定位具体版本与原文行号；核对完成后先显示确认回执。候选修改离开时使用软件内确认，取消保留修改；修复嵌套确认框焦点落到背景表单的问题。保留现有幂等、版本冲突、权限与部分采纳规则。
6. 私有 TXT/CSV、图片和 PDF 可在软件内预览。PDF 使用随应用打包的阅读组件、worker、字体和解码资源，支持翻页、缩放和自带文本查看；保留下载原件入口。读取仍经过原私有接口，关闭时取消请求并释放对象，不使用外部阅读服务。Nginx 为模块脚本/解码资源提供正确类型并保留 nosniff。
7. 采用 Base UI 1.9.0、Motion 14.1.0、Lucide React 1.55.0、PDF.js 6.4.299；锁定依赖并保存许可。统一分段选择、焦点、中文提示、线条图标和短促过渡，遵守减少动态效果设置；没有引入全局样式重置或持续装饰动画。详见 [依赖与参考](../ui-dependencies.md)。
8. 运行镜像、脚本、验收输出和迁移包切换到 JN-0010，旧批次保留。使用说明及可公开项目接续摘要同步更新。
