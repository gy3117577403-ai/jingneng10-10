## 目标与范围

用户授权完成公司资料与通用数据模块、权限、协同及紧凑中文界面。资料目录与组织关系分离；文件、版本与可配置台账一起管理。实现类别及单条资料授权、查看申请及有效期/撤销、审核发布、持久协作待办、导入预览校验与导出控制，复用现有应用与工作收件箱。

企业真实字段、复杂业务审批及外部数据库连接不代定。当前仅使用明确标识的虚构资料验收；内部目录、原件、账号和本地配置不提交公开仓库。真实模型继续保持未配置状态。

## 具体变化

1. 新增公司资料入口、目录树、内容列表、详情抽屉、版本历史、文件预览、我的权限、协作待办、导入和管理员配置。中文标签沿用公共工作区，电脑和手机分别处理滚动与底部操作；去掉重复标题，处理公共样式对弹窗宽度的覆盖。
2. 新增14张 `jn_data_*` 表。分类保存可配置字段；每条文件/台账保存不可覆盖的内容快照、文件引用及修订说明。新增、修订、上传、提交、指定另一人审核、退回、撤回、发布、归档与恢复完成闭环；新草稿不替换当前发布版。
3. 分类、工作组与组织关系独立。实现指定人员/工作组/所有在用人员，12类动作，缺省拒绝、明确禁止优先、单条资料完整替换规则。管理员配置权不自动读取内容；工作组撤员、角色/状态变化、重新请求及回执重试都重新鉴权。权限配置记录操作者、时间和当次规则快照。
4. 限时查看包含申请、指定审批、拒绝、撤回、撤销和到期；只开放获批版本，不提供下载/导出/编辑和后续版本权限。目录发现与内容读取分别判断；列表、搜索、预览、原件、导出和事项列表均受服务端控制。
5. 私有原件保存文件名、类型、大小和SHA-256，单份20 MB、单版本20份。PDF通过服务端Poppler生成分页图片，图片重新编码，文本按UTF-8预览；Office/CAD只保存原件并按下载授权访问。原件不通过公开存储链接提供。
6. 评论与协作任务固定到版本。派发只允许当前已有查看与协作权限的人员；支持接收、待补充、填写完成结果和取消，进入原工作收件箱。任务完成不自动形成生产或业务放行。
7. CSV/XLSX上传到个人私有批次，映射字段、检查必填/类型/选项/日期和重复编号。拒绝公式计算、超量行列和过大解压内容；确认时重新校验并整批事务生成草稿，支持幂等确认及未被使用草稿的整批归档撤销。按逐条权限导出已发布台账，并处理CSV公式注入字符。
8. 模块写操作使用短事务互斥与修订号，冲突拒绝旧写入；客户端防重复并保留失败输入，操作重试复用请求标识。已写私有文件在数据库事务失败时清理本次新增文件。
9. 增加虚构演示空间、维护组、独立审核员及查阅员；重复初始化不重建分类或重置密码。新增真实HTTP跨角色验收与CI步骤、配套恢复检查表项，验收输出改到本批目录，避免覆盖JN-0012证据。

已核对工作树、远端分支、更新编号、已有开放 PR；当前依赖 PR #11 尚未合并，因此从已核实的 JN-0012 分支接续，不从旧 main 重建。详细操作与边界见 [公司资料使用说明](../sem-company-data.md)。

## 剩余事项

企业正式分类字段、责任人员、工作组成员、敏感资料权限、审批层级和保留期限仍需配置确认。没有导入内部截图/原件或接通旧数据库，没有代建重复客户/物料主数据，也没有接入真实模型。

当前通用模块采用模块级写锁和应用内权限筛选，未作大规模容量/高并发验收。Office/CAD在线转换、文件全文/OCR、正式多级审批、在线共同编辑、主数据合并和病毒扫描服务不包含在本批。下载限制不防截图。完整旧方案中的扩展建议以实际使用说明为准，不声明全部已实现。

分支提交、远端CI、PR是否合并分别核对；同一逻辑工作继续本编号，不重复另建任务。用户真实资料与权限矩阵仅留本机私有规划，不提交公开仓库。
