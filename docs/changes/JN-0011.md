## 目标与范围

依赖 JN-0010（PR #9 尚未合并），继续实际运行的 ΣEM。用户授权推进高频销售页面、客户—询价—报价—订单关联、连续操作与可替换 AI 接入结构；成套、钣金同步验证。复用现有客户、报价明细和转订单能力，保持中文紧凑界面及资料访问权限。本批不做换电脑迁移，不配置真实模型，不代定企业正式计价审批规则。

## 具体变化

1. 询价可显式关联已有客户；客户详情提供新建询价入口和近期可访问询价。修复实际浏览器发现的入口参数被地址规范化丢失问题，并补充回归测试。
2. 人工确认需求、当前原件版本和商业配置后生成现有 Quotes 草稿，保存不可变来源快照。初始不生成明细或价格；报价、订单可回看当时需求及授权原件。新资料不会覆盖旧报价依据。
3. 询价事务锁、持久请求回执、询价版本唯一约束共同防止重复报价；原有明细转订单增加事务内状态/归属校验和唯一编码，避免并发重复转单。
4. 客户、报价、订单列表支持账号/标签页内筛选、页码、排序、滚动记忆；失败可重试，旧请求不覆盖新结果。客户与报价/订单主信息保存增加版本摘要校验；关键表单提供临时草稿、失败输入保留和提交锁。草稿不含文件，不是云端/跨电脑备份。
5. 报价、订单明细使用统一侧栏与未保存关闭确认，补齐输入标签、持续可见的新增入口及实时明细计数。常用页签保持直接可见，低频项移入“更多”；刷新保留页签。改善窄屏表格、中文日志/日期，修复客户无地图节点时的初始化错误。
6. 抽离 `ExtractionProvider` / `ExtractionGateway`，固定运行服务与版本，校验字段/来源/用量，记录耗时、尝试和可选用量。仅注册本机模拟器，没有真实模型、密钥、OCR 或模型网络调用。

使用、限制与接入契约见 [销售关联说明](../sem-sales.md)。未引入额外依赖，未复制另一套客户、报价或订单库。
