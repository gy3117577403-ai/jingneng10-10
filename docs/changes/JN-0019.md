## 目标与范围

按用户确认的方案实现组织架构和成员两页的真实组件预览，采用 shadcn/ui Base UI、紧凑排版和可操作的连线、折叠、筛选、详情面板。使用虚构演示数据，独立预览入口；本批不替换8090业务页面、不修改真实人员或权限数据。

## 具体变化

新增 `apps/ui-preview/`，真实安装 shadcn/ui Base UI/Nova、TanStack Table 和 React Flow。实现紧凑组织目录、共享主干架构图、成员表格、筛选、详情、演示新增/编辑、本地保存和 CSV 下载。统一标题18px、正文13px、表格行高40px及窄屏规则。使用17个组织和28位虚构成员，没有读取或提交内部人员原件。

将生成器自动创建的独立 `.git` 元数据移入本机忽略目录保留，预览源码由现有项目仓库直接管理，不作为嵌套仓库或子模块。操作说明、组件来源和实际边界见 [预览说明](../ui-component-preview.md) 与 [README](../../apps/ui-preview/README.md)。

2026-10-13 接续本编号，响应“交互太硬、按钮缺少反馈”：安装 Motion 14.1.0，补充按钮按压回弹、Tab 与目录选中指示、页签/面板进出、表格换位及减少动态效果适配。组织展开收起用同一逐帧坐标驱动节点和连线，并处理反向操作与新节点超出画布的平滑取景。保持原有紧凑密度与演示数据边界。

2026-10-13 继续按用户最新要求精修已有两页，保留模块、全部文案、虚构数据、品牌蓝和操作逻辑。改为平台系统字体，明确姓名/组织/岗位/辅助说明的层次，调整导航、内容表面、控件圆角、接触阴影与轻微高光。侧栏232px、标题栏54px、工具栏46px，表格42px，详情320px；组织节点212×80px、成员节点212×60px。按钮按压幅度改为98%，面板用短促连续过渡。树形布局改按每列轮廓安排分支，消除深层子树对无下级同级节点的无效推挤；自动取景优先可读性，覆盖式详情与窗口变化会避让实际面板宽度。新增减少透明度和增强对比度样式。没有新增业务功能、删减信息、改数据模型或替换8090应用。
