## 目标与范围

按用户确认的方案实现组织架构和成员两页的真实组件预览，采用 shadcn/ui Base UI、紧凑排版和可操作的连线、折叠、筛选、详情面板。使用虚构演示数据，独立预览入口；本批不替换8090业务页面、不修改真实人员或权限数据。

将生成器自动创建的独立 `.git` 元数据移入本机忽略目录保留，预览源码由现有项目仓库直接管理，不作为嵌套仓库或子模块。操作说明、组件来源和实际边界见 [预览说明](../ui-component-preview.md) 与 [README](../../apps/ui-preview/README.md)。
