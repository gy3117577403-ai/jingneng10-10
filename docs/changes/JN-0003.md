用户要求开始下一步，按已讨论的 F1 建设能实际操作的框架。依赖 JN-0002/PR #1 的运行底座，不重复建设或改写历史。成套、钣金同步验证，继续使用虚构资料；真实模型调用属于 F2。

本批闭环：新建询价与产品行、成员访问范围、私有原件及不可覆盖版本、任务分派/回复/确认/退回/挂起恢复、操作记录、带原件和清单的 ZIP 下载。正式报价、签约交接、价格规则及全企业岗位矩阵在后续适配。

“已完成”指本机实现与验收；远端 CI、PR 和合并状态以对应提交的 GitHub 记录为准。

## 具体变化

- 新增 Vue 3.5.43 / Frappe UI 1.0.0 员工工作台，询价列表、搜索/类型与状态筛选、详情、资料版本、我的待办、任务、历史与导出。支持桌面和手机宽度；前端在镜像中根据锁文件构建。
- 新增 8 个 DocType：询价、产品行、资料、文件版本、协作任务、活动、内部操作回执、导出快照。应用包升级为 0.1.0，没有移动或新建发布标签。
- 销售/技术演示角色分离，按询价负责人/协作者控制读取、列表、文件信息和下载；通用 REST 不得绕过动作服务写入，文件不能直接改公开、解绑或删除，单独分享受管记录被拦截。
- 请求标识防止重复写入；根记录版本与数据库锁防止覆盖并发修改；可重试死锁回滚整笔事务后有限重试。任务回复等待负责人确认，所有状态转换有历史。
- 原件以 SHA-256 追踪，同一资料相同内容复用当前版本，变更内容新增版本。单文件上限 10 MB，原件合计导出上限 50 MB，最终 ZIP 上限 64 MB。文本/CSV 预览；其他格式原件下载。
- ZIP 包含完整询价快照、产品、任务、操作历史、各版原件和校验清单。下载使用当前权限，撤销协作者后其旧上传与旧导出也不可继续访问。
- 保留 F0 页面和数据。升级前清理模块缓存再迁移，避免旧站点漏加载新模块；重复初始化保留已有密码、记录和原件。
- 新增可重复执行的 HTTP 验收脚本，CI 同时验证 F0、F1、重复初始化、重启和连续备份。

- `python scripts/smoke.py`：F0 的 11 项检查通过，包括实时连接正确/错误来源、独立 worker 和结果访问范围。
