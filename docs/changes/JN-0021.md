## 目标与范围

用户确认本轮优化数据库模块的功能与使用流程，第一优先级为分类、字段配置及成员协作权限。本批接续实际8090的公司资料和通用台账，依赖仍开放的PR #19，不从旧main重建。保留资料分类、企业组织、工作组、软件账号、版本审核与分动作权限之间的既有边界；不连接外部数据库，不代定企业真实授权。

## 具体变化

- 分类列表支持按名称和上级目录搜索，显示字段数、资料数（含归档）及默认权限配置状态。保存后可直接进入对应分类。
- 分类编辑拆为基本信息、台账字段、成员权限、核对并保存四步；支持逐步校验、返回调整、未保存关闭保护和失败保留。上级目录排除自身与后代。
- 字段支持顺序调整、六种既有类型、必填及选项维护，配套可试填的真实表单预览。已有资料时锁定原字段类型及删除，说明字段变更对旧草稿的影响，历史版本快照不变。
- 授权对象复用shadcn风格的Base UI可搜索选择器，不默认选中第一个人。按查阅维护、文件归档、协作查看申请分组；快捷项明确填充允许动作，不隐式开放导出、归档或全部权限。
- 新增仅配置管理员可调用的服务器权限预览，复用DataAccess实际身份与禁止优先规则，在内存中计算未保存规则。分类预览不写入规则、事件或请求回执；独立资料、版本与审核身份仍分别校验。输入变化后丢弃旧结果及晚到响应。
- 工作组可搜索软件账号、只看已选并提示本次新增/移出数量，过滤不丢失已选成员。列表显示引用该组的规则范围数量，不变更企业组织隶属或创建账号。
- 配套台账列表增加当前可读版本的业务字段列、显示列、类型及个人范围筛选和服务器分页前排序；URL恢复分类、关键词、筛选和列表页码，原文页码保持独立。导入继承当前分类，返回保留筛选；导出明确为全分类有权限的已发布资料。
- 详情提前说明字段过期、文件缺附件或缺另一位审核人等条件，服务器仍最终复核；修复只有发现权限时读取缺失字段快照导致的详情异常。
- 浏览器验收修复字段必填标签换行、关闭配置重复确认及“下一步”控件切换为提交按钮时提前保存的问题。步骤按钮和提交按钮分别挂载，明确阻止下一步默认提交，核对页必须再次点击保存。
