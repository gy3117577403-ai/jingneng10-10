## 目标与范围

用户确认界面审查后的实施方案。本批接续 JN-0015，统一中文文字、密度、颜色与组件状态，重做资料列表、原文阅读与协作、助手来源核对的连续体验，并将共用规范应用到相关既有业务页面。沿用已实现的数据、版本与服务器权限。依赖 PR #14，未合并；不从旧 main 重建。

## 具体变化

- 统一系统字体栈和中文层级，列表主文字14 px、原文与摘录15 px、辅助12–13 px；共用导航、收件箱及销售页面同步调整。修正长售前标题挤压业务类型标签和深色状态/占位文字对比度。
- 公司资料保留资料库、资料助手、协作待办三个日常入口，导入与权限配置收进管理；目录支持查找、分支折叠和整体收起。名称/台账与正文检索区分，内容按服务器权限显示。
- 详情改为连续阅读工作区，原文、信息、版本协作、历史和权限在同一处处理；日常阅读不再叠加详情与预览弹窗。保留修改/审批表单、服务器写入校验和应用内离开确认。
- 宽屏可并排核对来源与检索结果；窄屏优先显示来源。支持预览放大和专注阅读，版本切换清除另一版本的来源位置。返回保留分类、查询、列表滚动和焦点；切换主标签保留助手问题草稿，隐藏的检索页停止后台查询。
- 沿用原有服务器接口、原件与版本、分动作授权。没有新建企业部门或权限规则，没有用占位数据替换运行数据，没有接入外部模型。
