## 数据与回退

数据库和上传文件保存在独立命名卷；`.local/sem/runtime.env`、`compose.env`、`credentials.txt`、备份及迁移包均被忽略。备份短暂停止本演示写入服务，导出整库与文件，保留配套 APP_KEY 和 SHA-256 清单后恢复服务。

`restore-check` 只使用新建临时项目；成功后清理该测试项目，失败时保留。`restore-new` 会拒绝任何已有同名容器或卷，不覆盖现有环境。验证的是同一台电脑上的独立恢复；另一台电脑仍需按迁移包说明实际启动核对。

`package` 要求干净 Git，输出固定提交的源码 ZIP、Git 历史 bundle、运行镜像、数据库/文件/配置备份及校验清单。它包含本机密钥，只能私下转移，不能上传公开仓库；不包含旧 Frappe 数据、内部业务原件或完整聊天。迁移包首次生成结果见最终交付。

代码回退通过新的 revert 提交；数据库和附件回退依赖配套备份。停止新系统不影响保留的 Frappe 项目。本批未进行生产部署、未合并前序 PR，也未更改其他项目或全局 Docker 配置。
