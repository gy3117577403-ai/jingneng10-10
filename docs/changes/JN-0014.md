## 目标与范围

在现有公司资料模块补齐 Word / Excel 只读预览、附件正文检索、版本与位置定位、处理失败重试和虚构试用资料。先验收此批，再另行实施有来源、有权限的 AI 资料助手。目录仍是资料分类，不据此推断组织关系；不连接旧软件或正式生产。

## 具体变化

已实现私有文档处理队列、状态与恢复、Word / PowerPoint 分页预览、Excel 工作表只读阅读及 UTF-8 文本分段阅读。转换服务固定 Gotenberg 8.37.0 摘要，仅内部网络使用；不挂载原件或凭据，禁用外链抓取、远程下载和回调。

新增“正文检索”，返回授权范围内的台账字段和正文片段，带文件、版本、页码 / 工作表行号。默认只搜当前发布版，历史版显式选择；点击来源直接进入对应位置。未识别扫描内容、部分正文、超限与失败分别提示。后台状态持久化、独占执行、重复请求幂等；重试不覆盖原件。

复用原有权限、审批和协作；两类虚构试用资料贯通上传—阅读—人工核对—发布—检索—补充任务—新版发布。已在本机按已确认的内部分类框架建立分类草稿，未知字段与正式岗位权限保留待配置，不从目录推导组织。内部框架和实际配置记录仅存本机私有目录，不进入公开仓库。

阅读、搜索和位置链接沿用紧凑中文工作区；移动端表格内滚动、原文分页、版本标识、处理状态和失败重试可操作。格式与容量边界见 [使用说明](../sem-company-data.md)。
