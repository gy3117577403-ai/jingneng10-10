## 目标与范围

用户确认将新一轮精修应用到本机8090软件的组织与成员，以及导航、工具栏、筛选、表单、列表和详情等公共框架。JN-0019的5181组件预览保留为设计与交互参考，本批以实际应用接入和多轮浏览器对比验收为交付目标。

保持业务场景、模块、文案、数据、品牌与核心操作逻辑。采用系统无衬线字体、紧凑清晰层级、银白表面、克制透色与接触阴影，动效提供短促反馈与连续展开。用户提供的shadcn/ui、HeroUI、Aceternity、Magic UI和Ant Design按具体用途取用，记录真实依赖与参考边界，不混装整套主题。

## 具体变化

### 第三轮精修（2026-10-13 接续）

用户要求继续打磨组织与成员的字体排版、空间层次、按钮反馈与展开收起，保留业务和现有结构。沿用本编号、分支和PR #19，起点 `a76ef3f`。本轮收敛在组织模块，不新增业务、重新布置全局导航或更改数据模型。

1. 组织标题14px、成员姓名13px、辅助信息12px，页面标题17px；系统字体、数字等宽、图标重心和控件内边距统一。成员姓名保留清晰字重，不用过细文字制造轻盈感。目录和表头降低视觉权重，原字段、文案和数据保留。
2. 画布、目录、内容卡片和浮层区分材质：安静的中性底色、稳定的内容表面、细边缘高光与接触阴影。选中组织与普通成员具有不同层级；半透明只用于工具区与缩放控制。深色主题、增加对比度与减少透明度有对应处理。
3. 按钮按下轻微缩小并使用内凹阴影，释放后短促恢复；图节点与目录文字使用表面反馈而不平移，避免文字和连线端点脱离。使用既有shadcn/Base UI组合与Motion，不新增依赖。
4. 目录接入真实Base UI Collapsible，展开指示连续旋转，内容按测量高度过渡；收起中的子项退出键盘操作。架构图以被点击组织为锚点，展开380ms、收起280ms，可中途反向；节点与共享主干使用同一布局帧，保持用户缩放。
5. 详情保留至关闭过渡完成，修复直接卸载导致的突然消失；关闭后返回成员按钮焦点。保留筛选、三类资料标签、新增/编辑表单、权限和原保存逻辑。

### 第二轮精修（2026-10-13 接续）

用户审阅后确认继续改进全局导航一致性、工具栏层级、缩放后的可读性和表单/详情控件。沿用本编号、分支和PR #19，起点 `bf75f52`。本轮实际变化和验证单独记录，前一轮的通过记录不自动代表本轮通过。

设计约束：共用品牌/全局查找/账号导航；组织目录为模块内第二层，允许独立收起；架构图默认100%呈现，用户显式适应画布可缩小。界面标题18px，主要文字13px，说明12px；沿用 `#f5f6f8` 背景、`#ffffff` 表面、`#242a33` 正文、`#626d7b` 辅助色与 `#1769d2` 品牌强调，深色主题沿用共用语义变量。按钮按压、选项展开与详情入场采用已有短过渡，减少动态设置保持有效。

桌面结构：共用导航 | 组织目录 | 视图与当前组织操作 / 架构或成员 / 按需详情。窄屏通过共用功能查找与可收起目录保留入口，详情以浮层展示。组织连线和任职关系是本模块的视觉特征，不增加无业务依据的装饰。

1. 组织页改用实际应用的共用布局，品牌、全局查找、主题、通知、账号与左侧工作领域导航保持一致。组织目录可以独立收起；岗位、权限、变更记录入口继续按原权限显示。组织样式限定在模块与浮层中，避免覆盖共用导航按钮。
2. 视图切换与新增操作在第一行；当前组织路径、展开/收起和显示成员在第二行。成员列表取消重复外框，保留全部字段和原筛选。大屏详情停靠后给内容留出空间，较窄窗口使用可关闭面板，选中行与画布节点仍可识别。
3. 组织图列间距48px、行间距20px，初始和恢复按钮采用100%缩放。窄画布先呈现选中组织的父级及子级，其他祖先仍可平移查看；初始定位兼顾同列兄弟节点，避免边缘只露出一条卡片。显式适应画布仍能缩小全图，展开/收起保持用户缩放。
4. 表单短列表使用Select，长组织/岗位列表使用真实Base UI Combobox组合，可输入过滤、键盘选择和Escape返回焦点。保留必填校验、禁用/保存锁、未保存保护及原接口数据格式。修复深色主题的成员卡片、表单表面和悬停样式冲突。
5. 工作台列表直接显示已有业务数据的“下一步”操作名称；点击后的详情及业务跳转保持原逻辑。
