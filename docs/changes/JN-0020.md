## 目标与范围

用户确认将新一轮精修应用到本机8090软件的组织与成员，以及导航、工具栏、筛选、表单、列表和详情等公共框架。JN-0019的5181组件预览保留为设计与交互参考，本批以实际应用接入和多轮浏览器对比验收为交付目标。

保持业务场景、模块、文案、数据、品牌与核心操作逻辑。采用系统无衬线字体、紧凑清晰层级、银白表面、克制透色与接触阴影，动效提供短促反馈与连续展开。用户提供的shadcn/ui、HeroUI、Aceternity、Magic UI和Ant Design按具体用途取用，记录真实依赖与参考边界，不混装整套主题。

## 具体变化

1. 在实际8090应用增加共用精修层 `workspace-refinement.css`，统一系统字体、紧凑层级、中性背景、浅色表面、细边缘与接触阴影。沿用原导航、品牌、内容、权限和业务路由。组织页标题18px、一般页面标题20px，主要列表与控件13px，辅助信息11–12px；文档正文保留更适合阅读的字号。
2. 将JN-0019使用的shadcn/ui Base UI组合适配为实际应用控件，接入按钮、选择器、开关和操作菜单，保留MIT许可。复用已有Base UI弹窗/面板、Motion与Lucide。HeroUI用于按钮状态参考，Ant Design用于数据密度和列表层级参考；Aceternity/Magic UI的展示装饰本批未采用，不宣称五套库均已安装。
3. 组织图改为共享主干连接：每个父节点只有一条主干，节点与连接端点使用同一布局帧。子树按轮廓排列，展开/收起可连续打断；删除旧的按节点数量自动重新缩放，打开成员详情保持缩放并移动选中节点到可见区域。显式适应画布仍可使用，首次呈现保持文字可读。
4. 精修架构、成员列表、状态筛选、详情面板和编辑表单。主操作随视图区分新增组织/新增成员，选中行、展开状态、禁用与焦点有明确反馈。修复开关旧样式叠加、窄屏搜索输入宽度、详情遮挡当前节点和工作台分页不易看到的问题。
5. 共用导航、快捷查找、工具栏、工作收件箱、公司资料框架和既有业务表格采用一致密度。表格通过列键控制名称与编号的宽度，不依赖可变列序；长编号仍完整换行显示，行内查看按钮降低视觉权重。原筛选、排序、显隐、列序和接口保留。
6. 本机镜像接续为 `jingneng/sem:jn-0020`，应用、Web、队列与调度使用同一镜像。5181组件预览仍保留；本批交付的是8090实际应用。
