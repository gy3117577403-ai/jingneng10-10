## 目标与范围

落实已确认方案的第一轮：改善 8090 报价页面的视觉层次和下一步识别，区分当前处理与历史成本资料整理；提供客户资料入口、档案维护及报价双向关联。复用现有客户/联系人/地址/报价与组件，不另建客户数据库。依赖未合并 JN-0023 / PR #22。

## 具体变化

- 报价工作台采用银灰导航、灰蓝底面、稳定白色内容表面与明确状态色。保留紧凑字体、原业务字段、Base UI/shadcn 控件和 Motion 按压反馈；项目、客户、状态、金额和下一步操作分别对齐。
- 默认显示进行中报价，本页可编辑/待补成本与只读报价待整理分别统计；未成交、已关闭及已锁定记录不再因只读统一标为绿色完成。成本操作直接打开相应核价区。
- 客户资料列表支持名称/编号/联系人/电话搜索、状态筛选和分页；档案包含联系人、地址、负责人、备注和当前权限可见的关联报价。复用现有 companies 及子表，无新增迁移。
- 新建与维护客户、报价内补建客户、客户发起报价、报价打开客户档案和返回当前报价接通真实 API。补建前的项目输入保留；弹窗依次切换，长表单只滚动内容，标题/操作栏固定。
- 客户资料访问沿用已有 quotes-menu 与 companies-menu，维护限负责人或管理员；报价数量与列表仍按报价所有权过滤。指纹阻止过期覆盖，请求凭据处理重试，工作区写入锁串行化同名检查。已有联系人、地址及额外业务字段保留，不通过此界面删除。
- 本机 app/web/worker/scheduler 使用同一 jingneng/sem:jn-0024 镜像，8088 仍未启动；未合并或部署生产。
