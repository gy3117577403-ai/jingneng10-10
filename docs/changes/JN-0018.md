## 目标与范围

按用户选定的头像、组织关系图与浮层设计实现可操作的组织工作区。支持组织、岗位、成员、任职关系的增改与受控删除，头像上传、人物资料、一个总管理员和可分配的范围权限。先由总管理员维护，再向责任人交接；任职主管与系统权限分别建模。沿用既有应用和登录，不重新搭建系统。

## 具体变化

- 新增九张组织、任职、角色、范围授权、审计与幂等记录表；另以增量迁移保存固定导入标识，避免编辑成员编号后重复导入。
- 实现组织树、架构图平移缩放、分支展开、完整成员列表、人物固定面板、中文搜索与窄屏布局。沿用现有 ReactFlow、Base UI 和组件，不引入另一套前端框架。
- 组织支持五种类型；循环、超过十二层、同层重名、越权移动与存在关联时的删除均由服务端阻止。一个主职及多个兼任，任职变化保留历史，在用岗位不能删除或停用。
- 私有头像上传、裁切、服务端重编码和受权读取；实际人员缺少照片时显示姓名占位，虚构示例头像只用于隔离演示。
- 唯一组织总管理员、角色模板、到期授权及含下级范围。账号关联与创建需要核对身份，创建后不自动授权；主管标签不产生权限。
- 资料授权新增“组织直属成员”和“组织及下级成员”，保留既有逐动作允许/拒绝规则。成员停用后，相关账号的组织和资料权限重新判断；当前总管理员不能被旧账号管理页直接停用或删除。
- 写入共用策略锁、请求去重和版本冲突保护；审计不记录密码。浏览器表单失败时保留输入，未保存关闭通过软件内确认。
- 私有组织资料已在本机导入，全部人员作为待核对记录；三类项目纳入，按既有要求排除的组织未导入。同名不自动合并，未批量生成员工账号或责任人授权。
- 更新本机镜像至 `jingneng/sem:jn-0018`，8090运行。旧8088继续停用；真实模型配置保持现状。

使用方法与边界见 [组织工作区说明](../sem-organization.md)，视觉依据、三轮修正与运行截图索引见根目录 `design-qa.md`。
