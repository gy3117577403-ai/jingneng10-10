## 目标与范围

依赖 JN-0003 / PR #2 的工作台；开工时 PR #1、#2 均未合并，主干仍为记录基线。用户要求继续下一步，并明确选择先完成标识清楚的模拟测试闭环，再配置真实模型。

本批建设资料读取、来源快照、异步运行记录、结构化候选、人工接受/修改/驳回、受控写入及审计。成套与钣金同步验证。模拟适配器不调用模型，不证明识图或推理能力；真实供应商和凭据留到后续配置。

## 具体变化

- 工作台新增“AI 辅助”页面，展示模拟标识、资料选择、场景、后台状态、逐字段候选、原文行号/版本/摘要、人工修订和审核回执；可下载虚构成套/钣金示例。
- 新增 JN AI Run、JN AI Review，分别保存持久运行与不可覆盖的人工审核；应用包 0.2.0。沿用账号、记录和文件版本，不引入模型密钥或供应商依赖。
- 固定标签模拟器只解析 UTF-8 TXT/CSV，输出客户名称、期望交期和需求说明；缺项/冲突交由人处理。输出白名单和原文证据校验，无法引用的候选不进入审核。
- 请求回执、输入摘要、根记录锁防止重复和并发覆盖。候选本身不改询价；采纳时再验证当前权限与快照版本，修改经共享业务服务和同一事务保存。
- 运行与审核继承询价权限，通用 REST/分享不可绕过；撤销协作者后，快照与审核访问同步撤销。ZIP 包含所有运行、来源和审核回执。
- 后台任务先持久声明执行权，恢复器可重新投递无队列消息的排队记录，并用新执行令牌隔离迟到结果。失败可显式重试；不确定结果禁止自动/手动重试。模拟任务最多执行三次。
- 显式配置调度检查间隔 30 秒；Frappe 默认四分钟检查一次，不能仅凭每分钟 cron 就宣称及时恢复。恢复器每分钟到期检查，实际执行还受队列负载影响。
- CI 增加适配器约定、F2 HTTP 与重启恢复验收；说明见 docs/ai-review.md。
