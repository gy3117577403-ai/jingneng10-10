- 列表筛选与责任范围保存在链接中，提供服务器排序/分页、密度和列偏好；待办按根询价权限统计全部记录并定位具体任务/运行。

- 冲突重试保留用户最初选定的归档/恢复目标，避免另一人先归档后重试反而恢复；任务未完成等状态阻断只显示真实原因，不误称记录版本冲突。此交互仍列入浏览器复测。
