## 目标与范围

接续用户“开始下一步”，在已运行的 ΣEM 底座中实现中文售前工作台、成套/钣金询价、私有资料版本、模拟提取、来源核对、人工确认和操作记录。沿用已确认的模拟模式，不调用真实模型，不迁移旧 Frappe 数据，不切换生产。

开工时工作区干净，已 fetch 并核对全部分支与 PR；JN-0008 尚不存在。依赖未合并的 PR #6，不从旧 main 重建。新增界面遵循紧凑布局、明确主操作、按需展开和全中文文案。

## 具体变化

- 新增七张售前表、中文 React 工作区及记录级访问校验，成套/钣金共用一套入口、搜索、资料、AI 辅助和操作记录。幂等演示种子不覆盖已编辑数据。
- 原件按不可覆盖版本保存于私有存储；下载、提取和确认前校验摘要。新增版本保留旧文件，候选固定记录当时原文、版本、摘要、行号与引用。
- 固定标签模拟适配器只处理 UTF-8 TXT/CSV；缺失、多值冲突、非法日期不猜补。持久任务由 Redis worker 执行，调度器补投丢失任务，超时恢复和三次尝试限制保留执行记录。
- 负责人/管理员可修改及确认；指定协作者可上传、核对、提取。撤销访问后不能读取来源或重放旧请求。候选只有在人工勾选、填写说明并确认后才写入所选字段。
- 事务内记录版本校验、请求回执与并发去重；资料或询价更新后旧候选不能确认。确认/驳回保留操作者、时间、说明与修改前后内容。
- 表单错误保留输入，未保存修改使用软件内确认窗口，刷新可恢复处理结果；手机在列表与详情间切换。只是本批功能所需界面，全软件 UI 重构独立后续进行。
- 运行、测试与迁移包标签更新为 JN-0008，备份恢复清单新增售前表；旧迁移包保持不动。CI 加入实际售前 HTTP、队列和并发审核验收。
- 回归发现上游商机摘要测试使用随机商机状态，会随机得到已丢单却断言报价阶段。只将该测试前置状态固定为活动商机，不改变业务判断或降低断言。
